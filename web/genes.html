Gene Lab

RNA-style codon triplets compile to s-expressions that accumulate a diploid genome, then a resolver runs Mendelian dominance and prints a creature.

Gene Lab

seed feeds the MUT codon; same seed → same child 


        

          breed with another parent →
          

            The strand above is parent A. Provide parent B's strand and a
            seed — the child gets one random allele per trait from each
            parent (Mendelian gamete pick). Diploid parents (two alleles
            per locus) give the seed something to choose between; with
            one allele per locus, every seed yields the same child.

          quick strands
          
    
            
  • AUG CGA GCA ACA UCA GCG AUC GAU UAA — balanced creature, all traits
    • 
            
  • AUG CGA CGU GCA UAA — diploid size (70+30 averages to 50)
    • 
            
  • AUG GCG UAA — fragmentary genome (only color expresses)
    • 
            
  • AUG GCG GCG UAA — dom/dom tiebreak (hash-deterministic)
    • 
            
  • AUG GCC GCC UAA — rec/rec tiebreak
    • 
            
  • AUG CGA GCA ACA UCA GCG AUC GAU MUT UAA — full strand + MUT (try different seeds)
    • 
            
  • AUG CGA CGU GCA GCU ACA ACU UCA UCU GCG GCC AUC AUA GAU GAC UAA — diploid parent: two alleles per locus (use for breeding)
